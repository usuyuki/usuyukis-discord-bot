# 0012. チャンネル作成はDiscordの生権限ではなくBotコマンド経由で一般ユーザーに開放する

## ステータス

決定（Accepted）

## コンテキスト

一般ユーザーにもチャンネルを作成できるようにしたいという要望があった。素朴にDiscordの「チャンネルを管理（Manage Channels）」権限をロール経由で一般ユーザーへ付与すると、新規チャンネルの作成だけでなく、既存の非公開チャンネルの閲覧・名前変更・削除・カテゴリ移動・権限編集まで許してしまう。Discordのサーバー権限はチャンネル作成単体を切り出して付与する仕組みを持たないため、権限設定だけではこの要件を満たせない。

## 決定

一般ユーザーへ生の「チャンネルを管理」権限は付与しない。代わりにBot自身がその権限を持ち、`@Bot channel create <チャンネル名>` コマンド経由でのみチャンネル作成を代行する（`internal/domain/channel`, `internal/usecase/channel`, `internal/interface/discordbot/channel_handler.go`, `internal/infrastructure/discord/channel_creator.go`）。

- コマンドに管理者権限チェックは設けず、全ユーザーが利用できる
- 作成したチャンネルには作成と同時に権限オーバーライドを設定し、`@everyone`ロールに対してチャンネル閲覧（View Channel）を拒否する。これによりデフォルトでは作成者本人以外の一般ユーザーからは見えないチャンネルになる
- チャンネル作成を依頼したユーザー本人にはメンバー単位のオーバーライドで閲覧・投稿・履歴閲覧を明示的に許可する
- サーバー管理者（Administrator権限保持者）向けの明示的な許可オーバーライドは設定しない。DiscordはAdministrator権限を持つメンバーに対してチャンネル単位の権限オーバーライドを常にバイパスする仕様のため、`@everyone`を拒否するだけで管理者は引き続きチャンネルを閲覧できる
- Botの招待URLに `Manage Channels` 権限を追加する（README参照）

## 影響

- 一般ユーザーはBotコマンドを使わない限りチャンネルを作成・閲覧できず、既存の非公開チャンネルへの操作手段も持たない
- 「管理者以外には見えない」という要件は、Discordのadministrator-bypasses-overwrites仕様に依存して実現している。将来この仕様に変更があった場合は管理者ロールへの明示的な許可オーバーライドを追加する対応が必要になる
- Botトークンの権限（`Manage Channels`）が増えるため、Botが乗っ取られた場合の影響範囲がわずかに広がる。作成できるのはテキストチャンネルの新規作成のみで、既存チャンネルの改変・削除操作は今回のコマンドからは呼び出さない
